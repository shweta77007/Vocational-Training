# 🌸 About

**Employee Salary Analyzer** is a simple and user-friendly web application that helps analyze employee salary data efficiently.

Built using **Python**, **Flask**, **Pandas**, and **NumPy**, the application enables users to upload employee salary datasets, generate useful statistics, and visualize salary insights through an intuitive interface.

---

# ✨ Features

- 💼 Upload Employee Salary Dataset
- 📊 Analyze Salary Records
- 💰 Average Salary Calculation
- 📈 Statistical Summary
- 📝 Dataset Validation
- ⚡ Fast Data Processing
- 🎨 Clean & Responsive Interface

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/EmployeeSalaryAnalyzer.git
```

Move into the project folder

```bash
cd EmployeeSalaryAnalyzer
```

Install the required libraries

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
